# Changelog

The changelog for this mod lives in [changelog.txt](changelog.txt), in the
format the Factorio mod portal renders. Every release since 0.1.0 is in it,
and the portal's Changelog tab shows the same file.

This file used to carry a parallel Markdown changelog. It stopped at 0.4.45
while changelog.txt continued, so it was retired rather than left to mislead.
