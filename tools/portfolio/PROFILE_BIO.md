## Option A

I build multiplayer server mods for Factorio, mostly around Multi-Team Support: many teams on one server, each racing its own private copy of the same map. Brave New MTS, MTS Dimension Warp and Land Title Registry build on it, and Open Discord Bridge relays your server's chat to Discord. Diggy stands alone. All open source, all free.

## Option B

Multiplayer server mods for Factorio. Multi-Team Support gives every team its own private copy of the map on one server; Brave New MTS, MTS Dimension Warp and Land Title Registry build on top of it. Open Discord Bridge connects any Factorio server to Discord. Diggy is a standalone reimagining of RedMew's Diggy.

Everything is open source and free. Server operators and mod authors welcome on the Discord.
